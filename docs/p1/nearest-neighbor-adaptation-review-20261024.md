# QBA适配草案的开发期问题记录

2026-10-24。保留[原适配卡v1](nearest-neighbor-adaptation-draft-v1.md)，不把采后发现写成采前已经知道。

原卡提出按全部校准输出的85%分位确定长短分界。新完成的24条校准中，该分位数为384 token，等于后台输出上限；临时类别×输入桶中位数都不超过该值。按原卡“预测不大于分界归短”规则，9轮开发请求全部归短，长请求提拔无法发挥作用。

这不是一个可直接冻结为强最近邻的设置，也不能据此认定原论文QBA无效。当前尚未实现NN-QBA，更没有其性能结果。校准按类别平衡抽取，与主场景类别比例不同，分界总体和目标负载之间的关系也应说明。

G1前须审查分类总体、阈值依据、点估计和退化检查。在开发数据中比较可解释的候选分界，记录全部结果与适配差异，最终测试前锁定；不靠最终结果选择弱对照。若确实与其他规则等价，应保留映射，不虚增独立证据。

计算、来源哈希和逐轮比例见[临时预测空间诊断](../experiments/20261024-025138-p1-development-validation-v1/diagnostics-v1/README.md)。原题的M/B3主比较不因此更换。
