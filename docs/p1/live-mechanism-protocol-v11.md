# P1补强v11：统一预检与真实反馈准入原型

2026-10-26测量前登记。仍为P1开发与机制验证，G1未自动通过，最终数据禁止生成/访问，不启动320轮正式矩阵。

## 固定问题、实现范围和比较

检查三个具体问题：采前错误能否被统一门禁阻止；保持最少32条时后台是否有足够暖启动样本并实际执行更新；公共预算下后台能否推进，M与B3在真实反馈和真实队列状态下是否不同。

本轮实现Python客户端共享准入原型，连接既有本地3B与原引擎路径，测量真实模型输出及完成反馈。它不是正式C++ M/B3，也不替代G2/G3完整KV账本/异常验收。最多2个在途请求，按实际输入＋最大输出＋1保守预留，每条≤2048、总≤4096；HTTP结束后等到原生CAP RELEASE确认才归还外部额度并更新历史。不同进程时钟只各自计算差，记录客户端观察到原生事件的时刻，不跨时钟相减。

共同候选顺序：等待≥5秒的后台先选最老，否则交互优先、到达/ID平局；当前首候选硬额度不够时等待，不越过。空系统/受保护后台只绕过软预算，不能绕过硬限制。普通准入：所有在途请求在启动时记账的完整代理成本＋新请求成本≤预算。在途成本保留到确认释放，不伪装为准确剩余计算量。该简化对三策略一致，正式剩余量更新留G2。

比较B3_0固定余量0、B3_1固定余量1、M窗口32/分位0.8/最少32。B3_0为强主对照，B3_1只作校验余量作用的辅助。均用冻结v9点模型、同公开语法下限、6个类别×任务桶、同成本/容量/顺序/老化。反馈只用已正常完成、token已知且已见原生释放的正残差；预热不入历史，各轮重置。记录每次真实状态下三个策略的条件判断；它是同状态影子判定，不是另两策略的反事实性能。

## 资料与暖启动

补采校准seed31101..31106，各24条O指令资料，共144次单条测量；与旧v9的48条真实校准合用，每桶由8补到32，不降低门槛、不重复旧答案凑样本。点模型不重拟合，旧余量回退1保留。新校准只用来暖启动和标定公共成本，不参与独立验证。

新开发seed32100为预算可服务性探针；32101/32102为两组比较资料，各24份C指令资料，扩展为每轮200交互/30后台、100秒发送。编号从R100/R1000开始，固定字段、输出上限、桶与采样沿v9。仅这9个新seed允许生成，最终seed拒绝。全历史提示哈希查重、批内查重、实际分词可行性、上下文及暖启动计数统一门禁。冲突时只按预定nonce重新生成事实，最多100次，保存尝试哈希，不能根据模型输出筛选；不可行则停止。

公开占位分词与核对全部2^n语法分支在测量前保存。正确答案仅供离线评分，运行载荷白名单不含答案。旧校准使用真实旧输出与原记录哈希，不重新声称新样本。

## 公共预算选择与事先验收

用新144条校准原生prompt_ms/prompt_n及predicted_ms/predicted_n的中位数作成本系数；公共有效长度以B3_0＋公开核对下限计算，分别取I/B成本type7 P75的较大值Q。先在seed32100上只运行B3_0，依次最多试1.0Q和1.5Q：最小倍率若满足全部230条正常完成、30条后台中普通准入至少15条（50%），就锁定给所有比较轮。50%是机制诊断工程线，含义是多数后台不能只靠绕过；不是生产SLO。倍率1.5是测量前固定的可服务性候选，不参考M结果。

两个都失败就保留结果，停止比较并报告公共配置未通过，不再扩候选。技术记录错误立即停；性能/质量不佳保留，不能只重跑差臂。预算锁定后比较顺序：seed32101 B3_0/B3_1/M；seed32102 M/B3_1/B3_0，主对照次序平衡，辅助中位不作充分顺序控制声称。

最多144校准＋2×230探针＋6×230比较＝1984测量、9服务18预热、2002completion/4004CAP；只需一次探针则1754测量、8服务16预热。2组开发配对不作正式显著性/总体等价/增益保证。

每轮系统期限从计划到达180秒，统一截止280秒，传输360秒。客户端到达入队滞后、放行至发送滞后分别≤50ms，策略等待不计迟发。旧模型/运行库/来源前后核SHA，2slot/37层卸载检查，批次7200秒、raw≤1GiB、开批磁盘≥10GiB、阶段≥4GiB；只停止本脚本拥有的进程。记录GPU环境，后台普通/空系统/老化启动数、最大等待、全部终态、每桶更新、余量变化、影子差异与实际启动时刻。

## 分析与验收边界

全体计划请求进入分母；主指标计划至首内容P95，后台计划至完成P95，速率分母max(100秒,最后结束秒)，未知token不填零。答案正确与技术完成分开。独立核对真实释放/额度/反馈先后、6桶≥32、无未来反馈、载荷白名单、全部源与事件闭合。不同影子判定、余量相同、没有差异都如实报告；不把原型正确性、计数核对或“能更新但值不变”当M价值证据。继续使用固定的76分五项量表，仅按新增实质证据重新评分，不承诺达到90。
