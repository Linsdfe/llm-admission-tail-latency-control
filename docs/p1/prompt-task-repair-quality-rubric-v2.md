# 提示与任务修订v2：采前核读量规

登记日期：2026-10-24，Asia/Shanghai。本表在本轮真实生成前登记，只规定怎样逐条看回答。固定8条已知校准问题作配对诊断，另24条新开发pilot检查单一v2；它们均不是最终测试，也不拟合长度估计器。

## 每条回答分别记录什么

| 项目 | 核读要求 |
|---|---|
| 回应原任务 | 回答确实处理末尾原问题，数字和单位对应题目；计算结论能够从题目推出 |
| 规定格式 | 聊天为两句话；后台为六点，每点给可识别的依据和行动。格式与内容分别判断，不用正则匹配自动宣布完成 |
| 依据是否存在 | 引用的记录号、数字、数量关系真实存在；没有把不同快照当成已经确认的连续趋势 |
| 是否在解决问题 | 不能只抄整段记录、重复同一数字、复制提示要求或用空泛标题代替具体行动 |
| 不确定性是否保留 | 题目没有正常范围、阈值、物资使用规则、处理时长或故障原因时，不能补造并宣布确定结论；可以说明需核实的信息并提出核查步骤 |

各项用“满足、部分满足、不满足、无法判断”记录，另附原文摘录、具体理由和输出全文SHA256。没有统一加权质量分数，也不将EOS、长度合法或重复指标低直接转换为语义质量通过。

整体结论只在“全部原任务完成且无明确数值错误或严重无依据结论”时记为本条完成；只满足格式、只部分作答、内容不足或无法判断都不记为完成。该结论由助手阅读全文作探索性判断，不是独立人工盲评；助手知道提示版本，可能存在主观偏差。

## 按任务核对的具体事实

| 任务家族 | 需要核对的关键内容 |
|---|---|
| 借书与阅读 | 期限、每日页数和安排对应原题；若给总页数，应为天数乘每日页数，不能从背景分钟推导阅读速度 |
| 食谱换算 | 单份用量与份数的乘法正确，单位不改变；不能用时间安排代替配料换算 |
| 活动准备 | 准备和休息时间对应原题，并说明先后安排；无关背景不替代原要求 |
| 文具预算 | 支出受给定预算和单价约束；如报最大件数，整数计算正确；不混入无关时间管理 |
| 骑行准备 | 根据路线与休息信息给具体出发准备，不凭空确定速度、抵达时刻或安全保证 |
| 电脑散热检查 | 给出可执行的检查顺序，不把噪声持续时间或桌边间距直接当作已确认故障原因 |
| 学习与休息 | 对给定页数和每轮休息作安排；未提供专注时长时不假称能推算总用时 |
| 衣物分批 | 衣物与晾晒位置对应，分批方式可执行；如报批数，应正确取整，不凭空增加位置 |
| 温室记录 | 异常判断须有题目提供的范围或明确比较依据；没有标准时说明需核基准、复测和后续观察，不能宣布某些记录正常/异常 |
| 社区活动 | 人数与物资量引用准确，人员、物资、协调各有具体依据和行动；不足信息以核查建议表达 |
| 库存盘点 | 库存与当天领用引用正确，风险、盘点顺序、补货建议有对应依据；不能无限列数或保证未来不缺货 |
| 训练日志 | 训练与休息记录对应，给出节奏和记录改进建议；不能凭空给出身体状态或确定的合理范围 |
| 设备报修 | 等待时间、影响人数与处理/验证/通知安排关联；自拟优先规则须说明是建议，不能假称原题已有规则 |
| 课程反馈 | 已做与待订正数字对应，共性困难不能凭数量直接确诊；给订正和反馈核查安排 |
| 包裹配送 | 件数和剩余时间对应；缺少路线和单件耗时时不能保证全部按时完成，须有异常核对与交接行动 |
| 服务运行 | 请求与重试数字对应，排查、观测、恢复确认可执行；没有故障证据时不能断言根因或恢复成功 |

不同提示中的背景记录可能缺少时间顺序或正常阈值。引用具体数值作比较可以，计算和数据关系仍必须核对；不能把建议写成已观察事实。若某家族本轮未出现，只记录其规则，不补造样本。
