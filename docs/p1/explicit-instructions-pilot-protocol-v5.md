## 本轮问题和固定候选

v4格式约束已使24/24格式合法，业务只15/24正确；8道核对的28个标签全答“一致”，原资料14同14异。本轮保留已验证的语法限制，仅比较旧简写指令O与一个预先写好的明确指令包C，核查取数和比较是否改善。

| 任务 | O旧命令 | C明确命令 |
|---|---|---|
| 提取 | `提取{ids}。每行ID\|值。` | `提取{ids}对应的数值，不要复制编号作值。每行ID\|值。` |
| 核对 | `核对{ids}：同写一致，异写不一致。每行ID\|结论。` | `逐项比较A和B中{ids}的数值：相等写一致，否则写不一致。每行ID\|结论。` |
| 整理 | `按{ids}顺序整理。每行ID\|值。` | `只按{ids}顺序抄对应数值，不要抄其他行。每行ID\|值。` |

`{ids}`替换为原有公开目标列表。system仍为“只输出结果，无表头。”，资料标记、资料行格式不变。不增加示例、正确数值、正确标签或解释链；不调用普通程序替模型填答案。只测这一个候选，不根据输出继续改措辞。

两臂均采用同一GBNF语法，固定公开ID、目标顺序、行数及完整字段域：数字10—99全部90种，核对两个标签均可。新增解析器仅识别上述两种命令写法，同题O/C生成语法必须逐字相同；语法不读取源值、expected或回答。改变源值/答案而保留目标命令，grammar不变。

干预是这个明确指令包的整体变化，文字及token数也会改变。不把结果解释为某一句话或纯语义因素的独立效果，不作吞吐/时延收益比较。
