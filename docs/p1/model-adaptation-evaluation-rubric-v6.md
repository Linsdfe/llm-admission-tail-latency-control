# P1 模型适配 v6 评分标准

首次采集前登记。沿用冻结95/97的业务评分、字段规范和归一化规则。模型arm为A/B；指令instruction_arm始终C，检查提示时转换为C语义，不把模型代号当指令代号。

主指标为每模型完整正确题数/24：从原始资料独立重算答案，全部目标行按指定顺序和值匹配才算正确。允许既有规则中的无害首尾空白与换行；额外、漏行、错序、重复、错值都使完整业务判错。辅助指标为格式合法题数/24与正确目标字段数/88；额外输出不会提高完整正确率。比较任务另外公布真值“一致/不一致”各14个及实际输出分布，防止只输出“一致”造成误解。

逐题公布提示、原始输出、资料、预期结果与逐字段结果；按任务、类别、输入桶、服务块分组。24对题目固定分为双方正确、双方错误、A错B对、A对B错四格，配对不能改成历史14/24对当前结果。输出token只用原生predicted_n，不用字数估计。

独立审计不得导入新采集器或98评分器；可复用已经冻结的v5独立事实重算与字段核对函数。检查来源文件、全部题目保留、四块顺序、分词、实际原生回显、字段分母、CAP闭合、服务退出与计数。评分反例覆盖格式合法但值错、重复/漏行/额外行/错序、比较全写一致和模型/指令代号分离。

本轮是已见开发题的适配检查，不是新题泛化率、应用可靠率或调度收益。仅当B完整24/24且技术核对通过，才满足另行登记下一轮校准的入口条件。G1不自动通过。
