## 3. 选择规则先写清楚

公共候选只有按类别×输入桶的输出长度中位数与均值。保留原中位数作为基准，不按哪个候选更有余量来选择。

在5个校准seed中轮流留一组验证，其他4组拟合各桶。每折先求各类别×桶的绝对误差均值，再按目标主场景权重求MAE：聊天三桶权重67/230、67/230、66/230；后台三桶各10/230。五折等权平均，误差较小者推荐；差值不超过1e-9时取中位数。该选择仅使用校准数据，不读取新开发验证输出。最后用全部120校准拟合被选候选，保存训练文件SHA、候选全部折结果和确定性选择依据。

MAE衡量token误差，不等于调度收益或任务回答质量。不得用新开发结果重新选择或修改候选。若两者都差，报告误差与局限，不宣称已得到合格正式预测器。

## 4. 分类与上界诊断

主分类阈值固定采用按上述目标主场景权重计算的实际校准输出85%分位。每条校准样本权重为所属桶权重除以该桶20条，采用归一化加权经验逆CDF：累计权重首次达到0.85的最小观测输出值，不作线性插值。

旧的平衡样本type7输出85%分位与固定128 token只作敏感性参照，不能看新开发表现选一个容易击败的NN。固定128的依据是当前聊天64和后台384的预算间隔，不冒充原论文默认。所有规则均为预测≤阈值归短、超过归长，输出各类混淆表及I/B业务类别与S/L预测类别的交叉表。

聊天在目标负载占200/230，超过85%，且聊天输出不超过64。因此目标加权的85%实际长度阈值必不超过64；预测S/L可能与业务I/B完全重合。必须报告此退化或重合，不能将“全短消失”写成预测分类优势已经验证。NN请求级适配仍需G1和G2审查。

除点预测触顶率，还要报告正残差q.80/q.95加回预测、再按输出上限裁剪后的总上界触顶率。主诊断的残差取所选候选的校准留一seed预测误差`max(0,实际−预测)`，并另报最终拟合器的同样本残差作敏感性对照，不称统计覆盖保证。

同时列固定余量0/32/64/128与上述分位余量裁剪后的长度上界一致/不同次数。这里只检查静态长度上界，不实现或模拟真实软决策，不把它叫成M/B3实际决定、介入次数或收益。即使均值产生点预测空间，总上界仍可能触顶；不能据此宣布问题已经解决。
