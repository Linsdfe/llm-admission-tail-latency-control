# P1提示修订验证与后续任务边界

核读与收尾日期：2026-10-25；实际GPU采集：2026-10-24 19:56:25至20:00:04。**新提示让部分回答更贴题，但仍没有通过采前约定的任务完成检查。本次先保留结果，不把未完成的任务直接扩成负载实验。**

## 1. 这次改了什么，怎样验证

旧提示把问题写在前面，后面接很多参考记录。新提示把记录和真正的问题分开，在末尾重申原要求，并提醒信息不足时不能编造结论。原任务、数字、资料保留；没有把答案塞进提示。聊天仍最多64 token、后台384，温度0、自然结束、同一模型和引擎。

| 部分 | 具体做法 | 数量 |
|---|---|---:|
| 固定旧问题配对 | 已知8条问题提示，各重跑旧版和新版；两种先后交替 | 16条 |
| 新开发检查 | 新种子22001，12聊天、12后台，六个类别×输入档各4条 | 24条 |
| 预热 | 单独记录，不算测量或任务完成样本 | 2条 |

40条测量全部完成，机器耗时219.021秒，约3.65分钟。42次启动与释放逐ID闭合，服务退出码0。独立1764项数据检查通过，最大迟发3.321毫秒；46份项目源、8份引擎源、23项运行清单和模型核对一致。10-25另做389项来源/旧报告复核及8项单元检查，均通过。

本批所有请求都关闭提示缓存，实际缓存token为0；旧版也重新运行，不能拿旧缓存开启记录替代本次对照。新提示改变了输入长度，配对输入平均241.25→275.75 token；因此不能说“只移动问题位置”产生了全部差异，也没有据此比较调度性能。

## 3. 具体还错在哪里

| 任务 | 新提示下的原文或事实 | 问题怎样理解 |
|---|---|---|
| 准备69分钟，再休息2分钟 | “先安排活动准备69分钟，后安排休息2分钟。” | 顺序和数字回应了问题，较原先抄录更贴题；但要求两句话，实际只有一句。不能说这条内容全错，也不能说全部要求完成 |
| 每份62克、做7份食谱 | “62克/份 * 7份 = 434克。” | 乘法正确，同样只答一句；内容正确和格式满足分开记录 |
| 69天、每天2页阅读 | 138页计算正确，随后说“可用时间充足，无需担心” | 题目没有足够依据保证时间充足，不能把计算正确扩大成全部判断可靠 |
| 文具预算 | “减少购买数量，或者增加可用时间。” | 仍混入与预算无关的时间，没有完成两句具体安排 |
| 社区活动后台分析 | 从78名报名者推成需要78名现场协调人员 | 原资料没有这种一对一人员配置关系，是缺少依据的结论 |
| 温室后台分析 | 引用不存在的记录编号，并在未给标准时称环境极端 | 有条目标题和行动建议，不代表引用与分析有依据 |
| 库存后台分析 | 把无时间顺序的记录说成库存减少、领用增加 | 资料只能支持指定记录之间的比较，不能直接当成已观察趋势 |

全部40份原题和回答已按[采前核读量规](../../p1/prompt-task-repair-quality-rubric-v2.md)逐条检查，格式、题意、数值依据和复述分别记录。32份新版回答中，7份原任务内容满足，但没有一条同时满足全部原要求；这不等于32条内容全错，也不是总体业务合格率。它说明预定的“32份新版全部完成，才登记下一轮小负载”条件未满足。

这是知晓提示版本的助手探索性核读，不是学生或导师已经人工盲评。聊天输出另有20份交叉核对，具体证据和逐维判断见[全文核读](../../experiments/20261024-2000-p1-prompt-task-repair-v2/README.md)；客观长度和停因见[逐请求表](../../experiments/20261024-2000-p1-prompt-task-repair-v2/metrics.md)。

## 4. 对课题意味着什么，下一步怎样优化

本轮验证的是提示与任务要求，尚未实现或比较在线余量M和固定余量B3。回答质量问题不推翻旧负载下已记录的等待、吞吐和后台代价；旧数据应按合成执行需求解释，不能直接说系统更快交付了正确、可用的业务答案。G0用户决定保留，当前G1仍待审。

下一项应先把业务任务写得更明确，再登记新版本，避免继续只给开放分析要求：

1. 聊天采用题意和数字关系明确的短问答；后台先限定为有明确资料依据的提取、核对和整理。缺少阈值、时间顺序或人员规则时，输出待核实事项，不要求凭少量随机数字推出诊断。
2. 给出可检查的必答字段与事实边界，把“答到关键内容”与“两句/六点”等格式分别验收。不能在看过本批结果后放宽本批标准；新要求另立版本并说明为什么修改。
3. 先验证新任务是否适合当前模型，再确定输出预算、重新核长和开发负载。预算依据任务需要，不依据哪种设置更容易让复杂调度获胜。若改模型或预算，也要登记新基线。

本轮没有自动扩大9轮负载，也没有临时改成v3继续筛成功样本。后续任务变更后，旧120条校准、64长短分界和旧性能数据不能直接当作新任务的已验证参数。原研究问题继续保留，后续仍须同信息、公平地比较M/B3的真实决定、收益与代价。
