# P1可核对资料任务验证

2026-10-25，Asia/Shanghai。当前P1，G1待审。

**任务已经缩成“照资料找数、比较两份资料、按要求排列”，但本轮24道题只有9道完整答对。现在的问题仍是模型能否稳定完成任务，暂不能把这批负载用于评价调度收益。**

## 这次具体做了什么

先登记[协议](../../p1/verifiable-task-pilot-protocol-v3.md)和[判分规则](../../p1/verifiable-task-evaluation-rubric-v3.md)，再运行固定的一个提示版本。提取、核对、整理各8道，共12道短请求、12道后台请求。答案必须来自题目资料，不再要求模型分析原因、预测趋势或安排人员。

例如提取题要求输出`R1|17`；核对题要求比较同一编号在A、B资料里的数值，输出`一致`或`不一致`；整理题只输出指定编号，并按指定顺序排列。短请求查1个或2个编号，后台请求处理6个编号。

正确答案单独保存在本地评价文件，未作为额外答案字段发给模型。两个核对程序分别按原资料重新算答案，并检查资料、目标编号、顺序与真实提示一致。判分允许无意义空白，不能改数值、补漏项、删多余说明或调整顺序。采前15项无模型测试全部通过，评价程序版本在真实输出前另存SHA。

实际于10:14:18—10:15:59在WSL运行，采集程序耗时100.803秒，另有2条预热。模型、引擎、两执行位置和输出上限64/384均沿用固定设置，关闭提示缓存。24道题全部保留，没有删掉失败题或同批改提示续筛。

## 现在怎样推进

本轮未通过任务验收，G1继续待审。下一步先另登记输出约束验证，检查能否解决漏编号、多余行、错误标签；数值和比较结果仍须逐项独立核对，不能只靠格式通过。原始v3提示、量规和失败结果不改，后续任何修改都另立版本，不只挑这9道成功题扩大负载。
