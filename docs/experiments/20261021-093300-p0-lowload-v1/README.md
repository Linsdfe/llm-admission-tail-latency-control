## 研究问题和协议

比较同期交互独占 C（200 条）与低强度混合 L（相同交互加 10 条后台）；后台每 10 s 一条，按预先固定编号稀疏化。

## 判读与边界

本批次未同时满足三对均无明显持续积压且 P95 配对增加均≥100 ms 的预设筛选条件；按逐对结果判断，不能只凭完成者 P95 宣称假设成立。
100 ms 是事先固定的探索性工程门槛，不是正式 SLO 或显著性阈值。三对不提供正式显著性结论，不对共享队列请求逐条 bootstrap。
L 同时降低后台请求数、工作量并改变缓存路径；与旧 E1 的比较仅为跨批次背景参照。本实验没有识别长度构成的独立作用，未验证自研 C++ 策略、KV 账本或长期公平性。固定相位、合成短输入、单设备模型与宿主应用竞争均限制外推。
实际长度及缓存差异完整报告，不按结果删样凑等量。服务端排队/输入处理/交付分段仍未知，TTFT 不能全部称为纯排队。
G0 仍待文献、范围、人时/机时与评审确认；P0 未标为全阶段完成。
