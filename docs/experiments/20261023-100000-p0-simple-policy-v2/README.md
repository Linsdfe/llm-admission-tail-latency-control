## 判读和边界

简单规则若改善且代价能接受，优先作为下一阶段基线；若后台代价大，先研究优先级/老化/配额取舍。未改善时先看是否产生实际启动次序差异，以及等待是否由已运行的两个非抢占任务主导。当前未实现完整硬 KV 账本，也未测试复杂算法的增量收益。

单设备、单模型、固定合成内容和默认前缀缓存限制外推；实际长度与缓存变化完整报告，不事后删样凑等工作量。三对运行是重复单位，2760 条共享队列请求不能视为2760次独立实验。
