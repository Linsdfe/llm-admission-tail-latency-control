## 数据怎么理解

c22八字符重复超额比率从0.840增至0.920，与读到的重复63一致。c08该比率仅约0.002和0.003，却一直列无依据的变化数字。因此不能靠一个重复分数自动判回答可用。指标定义和4/8/16字符完整数据见客观表及summary。

同一提示的高档回答也不一定更长。c18高档52 token，低档384 token，文本不是原回答继续延长；c23也有用词差异。缓存、顺序与数值执行仍可能影响生成，本探针没有分离原因，不能把每一处文本差异都归因于上限。8对属于同一服务会话，不作8次独立性能重复。两档输出合计1777和2544 token只描述这组请求，不用于吞吐或总体效率结论。

## 对后续工作的影响

保留主方案64/384和全部旧数据，不因想给复杂算法制造空间而放宽输出预算。G1前需要另立版本核对提示与任务要求是否合理，并在新开发数据上检查回答是否实际完成；如果继续采用当前合成负载，论文只能据实描述其执行需求，不能把较快首响应当成较快交付可用答案。任何提示或预算修订都要重新核对实际长度和负载，不直接继承旧9轮的性能结论。

本探针不进入120条校准或120条新开发验证，不选择预测器或M/B3参数，不评判复杂调度是否值得，也不批准G1。原始文件中的质量pending字段是采集时状态，原样保留；本页与assistant-review.json是随后追加的核读记录。
