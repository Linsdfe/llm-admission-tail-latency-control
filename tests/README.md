# 验证范围

- `unit/`：完整硬预留、分配粒度、边界拒绝、误差更新、软硬隔离、老化与幂等回收。
- `integration/`：真实引擎正常/取消/超时/错误路径、取消完成竞争、slot 复用、小轨迹计时与计数闭合。

`integration/verify_open_loop.py` 已覆盖客户端完成/拒绝/总超时/取消/失败/截止未完成、未释放请求、HTTP chunk 与 UTF-8 分段、心跳/空块、完成/取消竞争及发送能力校准。真实引擎的取消、截止和恢复由 `scripts/replay/70_run_prestudy.py` 留证。二者不能替代后续 C++ 容量硬账本、序列清理与幂等回收验收。

稳定性和性能证据按 run_id 存入 results；具体结果以运行状态与报告为准，存在测试文件不等于所有工程验收已通过。
