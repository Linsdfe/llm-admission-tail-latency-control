# 指标与图表分析

先检查全部终态计数闭合、请求 ID 与时间字段，再计算交互 P50/P95 TTFT、后台等待/完成、窗口吞吐和完成比例。排空另记，不把分段 P95 相加。

输入引用不可变原始 run_id，输出写入 `results/processed/` 和 `results/figures/`，记录分析版本和输入摘要。正式区间以预注册的独立运行或时间块为单位。

- `10_check_sanity.py`：小轨迹正常路径审计与运行清单，适配 `60_run_sanity.sh` 的目录。
- `80_analyze_prestudy.py`：第七、八步批次审计、三组 E0/E1 配对统计、后台代价、长度/缓存与全部终态。使用 `--batch <完整批次> --output <新目录>`，不覆盖旧分析。

小型可发布报告与摘要可版本化放在 `docs/experiments/<batch_id>/`，完整原始记录仍留在 `results/raw/`。三个重复的探索性结果不作正式显著性结论；原始数据被 Git 忽略，论文使用前仍需校验并建立数据备份。
